# 三部分评标核验规则原始资料

本目录保存本轮规则开发所依据的完整原始文件，供规则追溯、系统迁移和回归测试使用。

| 文件 | 用途 |
|---|---|
| `评审规则8.12.xlsx` | 三部分、41 条评审规则的业务来源 |
| `评标报告智能核验场景用例流程V2.0.xlsx` | 场景流程、用例及规则落点参考 |

系统实现将规则划分为：

1. 项目基本信息、评标结果与推荐、报告签章与附件；
2. 招标公告与发售情况、开标情况、评标委员会组成；
3. 资格审查、符合性审查、详细评审与评审结果汇总。

代码中的稳定规则编号、状态和执行器以
`app/services/evaluation_rule_service.py` 为准；原始 Excel 用于核对业务来源，不能直接替代运行时规则目录。
