## Dify 建库建议

- 知识库名称：`招投标法规知识库`
- 数据源：上传 `dify_upload` 中的 8 个文件
- 分段模式：父子分段
- 父分段：按章节或约 1500–2500 字
- 子分段：约 300–600 字，重叠 50–100 字
- 检索：混合检索
- Top K：5
- Score 阈值：初始设为 0.35，之后按测试集调整
- 检索结果必须保留文档名称和原文片段，不允许模型脱离检索结果编造法条

## 更新规则

法规库用于辅助审查，不替代专业法律意见。每次更新应记录来源 URL、发布日期、
施行日期和效力状态；草案、征求意见稿、新闻解读不得与现行正式文本混入同一库。
